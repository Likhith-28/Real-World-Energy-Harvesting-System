# Real-World Pedal Energy Harvesting – Power Prediction

## 📌 Project Overview

This project combines **piezoelectric energy harvesting and machine learning** to predict the electrical power generated by human footsteps.

Piezoelectric floor tiles convert mechanical pressure from footsteps into electrical energy. The collected sensor data is analyzed using machine learning regression models to understand how factors such as weight, step location, voltage, and current influence power generation.

The project aims to support smarter energy monitoring and improve the analysis of footstep-based energy harvesting systems.

## 🎯 Objectives

- Analyze electrical energy generated by human footsteps using piezoelectric sensors.
- Collect and preprocess sensor measurements.
- Perform exploratory data analysis (EDA) and correlation analysis.
- Engineer relevant features for machine learning.
- Train and compare multiple regression models.
- Identify the best-performing model using standard evaluation metrics.

## 📊 Dataset Overview

The dataset contains measurements collected from a piezoelectric footstep energy harvesting setup.

| Feature | Description |
|---|---|
| Weight (kg) | Weight applied to the tile |
| Step Location | Footstep position: Center, Edge, or Corner |
| Voltage (V) | Voltage generated by the piezoelectric sensor |
| Current (A) | Current generated by the sensor |
| Power (W) | Target variable for power prediction |

## 🔄 Project Workflow

1. **Data Collection:** Collect weight, step location, voltage, and current measurements from the piezoelectric setup.
2. **Data Preprocessing:** Check for missing values, inconsistencies, and erroneous sensor readings.
3. **Feature Engineering:** Encode categorical step locations and select relevant input features.
4. **Exploratory Data Analysis:** Visualize distributions, identify outliers, and examine correlations between variables.
5. **Model Training:** Train multiple regression models using the prepared dataset.
6. **Model Evaluation:** Compare model performance using R² Score, Mean Absolute Error (MAE), and Root Mean Square Error (RMSE).
7. **Power Prediction:** Use the selected model to predict power generation from input measurements.

## 🤖 Machine Learning Models

The following regression algorithms were evaluated:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

### Model Performance

According to the project report, the Random Forest Regressor achieved the best overall performance among the evaluated models.

| Model | R² Score | MAE | RMSE |
|---|---:|---:|---:|
| Random Forest Regressor | 0.9685 | 0.0399 | 0.0990 |
| Gradient Boosting Regressor | 0.9542 | 0.0700 | 0.1194 |
| Decision Tree Regressor | 0.9405 | 0.0478 | 0.1362 |
| Linear Regression | 0.7839 | 0.2029 | 0.2594 |

## 📈 Exploratory Data Analysis

The analysis in the report includes:

- Boxplots to examine outliers in weight, voltage, current, and power.
- Power distribution comparisons across Center, Edge, and Corner step locations.
- Correlation matrices to analyze relationships among the original and engineered features.
- Actual-versus-predicted plots to assess model performance.

The report identifies voltage as having the strongest positive correlation with power, with a reported correlation coefficient of approximately 0.99.
